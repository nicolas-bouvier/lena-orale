# Lena à l'oral

Page personnelle pour parler allemand à voix haute avec Lena, une professeure virtuelle.

- Voix et conversation : Gemini Live (Google, offre gratuite). La clé est saisie dans la page et reste sur l'appareil : elle n'est jamais dans ce dépôt.
- Avatar : modèle « brunette » de Ready Player Me (CC BY-NC 4.0), chargé depuis jsDelivr ; animation [TalkingHead](https://github.com/met4citizen/TalkingHead) et [HeadAudio](https://github.com/met4citizen/HeadAudio) (MIT).
- Usage personnel, non commercial.
